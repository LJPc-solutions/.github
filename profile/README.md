# LJPc

LJPc builds custom software, apps and websites in Assen, the Netherlands, and offers hosting. This is where we publish the parts that other people can use too.

## FreeScout modules

Modules for [FreeScout](https://freescout.net), the open source help desk.

- [Calendar](https://github.com/LJPc-solutions/freescout-calendar-module): calendars in FreeScout, with two-way sync for Google Calendar, Microsoft 365 and CalDAV, and calendar invites from conversations.
- [Alternative signatures](https://github.com/LJPc-solutions/freescout-alternative-signatures-module): several signatures per mailbox, chosen per conversation.
- [Internal conversations](https://github.com/LJPc-solutions/freescout-internal-conversations-module): conversations that only the people added to them can see.
- [Cleanup](https://github.com/LJPc-solutions/freescout-cleanup-module): Artisan commands that remove old conversations, notes and attachments.
- [WHMCS integration](https://github.com/LJPc-solutions/freescout-whmcs-module): WHMCS customer details, invoices, services and domains inside FreeScout.

## Data, libraries and tools

- [Nederlandse-adressen-en-postcodes](https://github.com/LJPc-solutions/Nederlandse-adressen-en-postcodes): every Dutch address with postcode and coordinates, as CSV files for the whole country and per province, released as CC0. The same data is available as a free API at [gratis-postcodedata.nl](https://gratis-postcodedata.nl).
- [Pure-PHP-DoH-Client](https://github.com/LJPc-solutions/Pure-PHP-DoH-Client): DNS lookups over HTTPS in PHP, without extensions or dig. Install with `composer require ljpc/pure-php-doh-client`.
- [laravel-cloudns-library](https://github.com/LJPc-solutions/laravel-cloudns-library): Laravel package for the ClouDNS API.
- [Plesk-Brand-Manager](https://github.com/LJPc-solutions/Plesk-Brand-Manager): Plesk extension that shows different branding per hostname or IP address.
- [HostingPanelBoilerplate](https://github.com/LJPc-solutions/HostingPanelBoilerplate): white-label reseller panel in plain PHP for selling domains and Plesk hosting.
